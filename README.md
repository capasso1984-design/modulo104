# Modulo 104

App gratuita per compilare dal telefono il modulo mensile di programmazione dei permessi L.104/92.

- Funziona su iPhone e Android (si aggiunge alla schermata Home) e anche senza internet.
- I dati personali e la firma restano **solo sul telefono**: nessun dato viene inviato a server.
- Il modulo da compilare si carica come file `.m104`, preparato sul PC con l'app "Modulo 104".

La libreria [pdf-lib](https://github.com/Hopding/pdf-lib) è distribuita con licenza MIT.
